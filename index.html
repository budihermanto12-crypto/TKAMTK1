Integrasi Google Spreadsheet

Simpan otomatis hasil & nilai ujian siswa dari GitHub Pages

URL ini tersimpan lokal di browser Anda (`localStorage`).

🛠️ Langkah Singkat Setting Google Sheet:

  1. Buka Google Sheet baru, beri judul header baris 1: Waktu | Nama | Absen | Nilai | Status | Benar | Total Soal
  2. Klik menu Ekstensi → Apps Script.
  3. Hapus semua kode, lalu salin dan tempel (copy-paste) kode di bawah ini:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.waktu_selesai || new Date(),
    data.nama,
    data.absen,
    data.skor,
    data.status,
    data.jumlah_benar,
    data.total_soal,
    JSON.stringify(data.detail_jawaban)
  ]);
  return ContentService.createTextOutput(JSON.stringify({"status": "success"}))
         .setMimeType(ContentService.MimeType.JSON);
}
